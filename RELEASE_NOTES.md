# Soul Browser v1.0.0-beta

Welcome to the first public beta release of Soul Browser!

### Features
- **Native SwiftUI Shell:** Buttery smooth macOS integration without the Electron bloat.
- **CEF Engine:** Full Chromium rendering and V8 JavaScript engine under the hood.
- **!Bangs Integration:** DuckDuckGo-style quick search right from the URL bar (e.g. type `!w macOS`).
- **AI Tab Grouper:** Smart contextual grouping for your workflow.
- **Extreme Memory Optimization:** Site isolation and V8 overhead trimmed to keep RAM usage incredibly low.
- **Privacy First:** Built-in anti-phishing scanner and secure local keychain.

### Bug Fixes
- Fixed an issue where the buttons in the onboarding flow were sometimes unresponsive or unpredictable.

### Installation
1. Download `Soul-macOS.zip` below.
2. Unzip and drag `Soul.app` to your Applications folder.
3. Right-click and select "Open" (since it is a beta, you may need to bypass the unverified developer prompt).
4. Enjoy a faster, focused web!
